# 台灣格雷蒙工商儲能業務提案

電池材料開發部提案的十二頁網頁簡報。含政策比較、表後儲能重繪圖、互動節費與回收試算、長庚原簡報案場照片、安全與部門年度開發計畫。

操作：頁尾與章節導覽切換、左右鍵切換、F全螢幕。手機可上下捲動各頁，照片可放大，瀏覽器列印會輸出所有頁。

資料來源在第十二頁；圖片來源在 `asset-sources.json`。供應商資料不等於已驗收或收益保證。歷史成本、電價與內部計畫皆標示邊界，正式案件應更新負載、報價、契約與核定資料。

照片由使用者提供的長庚V7簡報擷取，版權歸原權利人。圖解為重繪示意。提供同步更新的Word與Excel下載；未公開原始整份PDF。網頁為公開GitHub Pages，noindex為搜尋引擎指示，非存取控制。
